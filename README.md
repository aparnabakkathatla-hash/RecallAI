\# RecallAI 🧠



AI-powered second brain for students.



\## Vision

Never forget what you learn.



RecallAI helps students:

\- Store learning memories

\- Track concepts

\- Revise using active recall

\- Generate quizzes

\- Analyze PYQs

\- Build personalized learning paths
